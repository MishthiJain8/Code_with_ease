# Sort Studio

A clean, cute Java sorting-learning site built with Streamlit.

## Topics
- Selection Sort
- Bubble Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Recursive Bubble Sort
- Recursive Insertion Sort
- Arrays

## Design direction
The interface intentionally avoids emoji-heavy decoration and oversized cards.
The sorting visualizer represents each array element as a penguin. The penguins
physically change position as the algorithm progresses.

Character artwork is referenced from free LottieFiles animation assets. Sorting
movement and interaction are implemented locally in HTML/CSS/JavaScript.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Push the folder to GitHub, then choose `app.py` as the main file in Streamlit Community Cloud.
